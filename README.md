# LOS FastAPI Data Integration

## What this service does
- `POST /api/v1/underwriting/data-snapshots`: fetches and validates source data from LOS.
  - `LEAD_ELIGIBILITY`: Bureau/CIBIL `analysedCic`
  - `PRODUCT_UNDERWRITING`: GST, Platform, and BSA
- `POST /api/v1/underwriting/results`: validates a future result object and forwards it to LOS only when `LOS_RESULT_POST_URL` is configured.
- `GET /health`: service health check.

This service does **not** implement the Underwriting Engine, rules, model, or credit decision. The Engine is not ready yet. Until then, the data snapshot endpoint lets the team test data retrieval, payload shape, and validation.

## Endpoints

### Fetch Stage 1 data
`POST /api/v1/underwriting/data-snapshots`

```json
{
  "rfid": 228725,
  "stage": "LEAD_ELIGIBILITY",
  "loan_product_ids": {},
  "include_raw": true
}
```

### Fetch Stage 2 data
`POST /api/v1/underwriting/data-snapshots`

```json
{
  "rfid": 228725,
  "stage": "PRODUCT_UNDERWRITING",
  "loan_product_ids": {},
  "include_raw": true
}
```

Optional overrides can be passed in `loan_product_ids`, for example:
`{"BUREAU": 138, "PLATFORM": 81, "BSA": 88}`.
Confirm IDs for each LOS product before production. GST uses `objectId` and `objectType` query parameters, not `loanProductId`.

### Validate/post result (future integration)
`POST /api/v1/underwriting/results`

```json
{
  "request_id": "sample-request-id",
  "rfid": 228725,
  "stage": "PRODUCT_UNDERWRITING",
  "status": "COMPLETED",
  "decision": "PASS",
  "reason_codes": [],
  "reason_messages": [],
  "credit_limit": {
    "currency": "INR",
    "recommended_amount": "500000.00",
    "approved_amount": null
  },
  "result_schema_version": "1.0",
  "evaluated_at": "2026-10-24T10:00:00Z"
}
```

The example amount is illustrative. No decision is generated by this API. Do not set `LOS_RESULT_POST_URL` until the LOS team supplies the real endpoint and agrees the schema. Result forwarding is disabled by default.

## Run on Windows / PyCharm

1. Create and activate a virtual environment.
2. Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

3. Set environment variables in the PyCharm Run Configuration or PowerShell. Example:

```powershell
$env:LOS_AUTHORIZATION_VALUE = "YOUR_VALID_TOKEN"
$env:LOS_BASE_URL = "https://los.glaas.co"
$env:LOS_TIMEOUT_SECONDS = "180"
uvicorn main:app --reload
```

Do not paste the real token into source code or commit it to Git. If LOS requires a `Bearer` prefix, set the environment variable to `Bearer YOUR_VALID_TOKEN`; otherwise use the exact value required by LOS.

4. Open Swagger UI at `http://127.0.0.1:8000/docs`.

## Error handling
The API returns a consistent object with `request_id`, `correlation_id`, `status`, and `error.code/message/details/retryable`.
- `LOS_AUTH_NOT_CONFIGURED`: service auth is missing.
- `LOS_SOURCE_TIMEOUT`: LOS call timed out; retryable.
- `LOS_SOURCE_HTTP_ERROR`: LOS returned an HTTP error.
- `LOS_INVALID_JSON`: LOS response was not JSON.
- `LOS_RESPONSE_SCHEMA_INVALID`: response shape was not as expected.
- `REQUIRED_SOURCE_DATA_MISSING`: required source object/key was missing.
- `DATA_CONTRACT_BREACH`: request body failed Pydantic validation.

A technical error is never converted into a credit FAIL decision.

## Important implementation notes
- The provided Platform and BSA `loanProductId` values are examples; confirm the product-to-ID mapping with the LOS Tech Team.
- The GST response schema has not been supplied. This code checks that it is JSON but does not assume undocumented GST field names.
- The full LOS source payload is returned by default for integration testing. Protect this API with network access controls and proper authentication before exposing it outside a trusted development environment; source payloads may contain sensitive personal/financial data.
- For production, add OAuth 2.0/client credentials for callers, durable audit storage, idempotency, rate limiting, and tests. The companion API signature document defines a separate future Underwriting Engine contract with asynchronous jobs, webhooks, and status recovery. This service does not implement that Engine contract yet.
